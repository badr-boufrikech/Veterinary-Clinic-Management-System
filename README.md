
# VitaVet — Veterinary Clinic Management System

A C++ console application designed to manage veterinary clinic operations, including animal registration, medical consultations, financial tracking, and report generation.

## Features
- Register dogs, cats, birds, and reptiles.
- Manage animal records with unique identifiers.
- Record veterinary consultations and calculate fees.
- Display consultation history and financial summaries.
- Export clinic reports to a text file.
- Handle invalid user input with exceptions.

## Technologies and Concepts
- C++
- Object-oriented programming (OOP)
- Inheritance, polymorphism, abstraction, and encapsulation
- Standard Template Library (`std::list`)
- Dynamic memory management
- File handling and exception handling

## Build and Run
Requires a C++17-compatible compiler.

```bash
g++ -std=c++17 main.cpp VitaVet.cpp -o VitaVet
./VitaVet
```

On Windows, run `VitaVet.exe` after compilation.

## Project Structure
- `main.cpp` — Main menu and program execution
- `VitaVet.hpp` — Class definitions and function declarations
- `VitaVet.cpp` — Application logic and implementations
